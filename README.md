# TradingView Themes

100+ professional TradingView chart color themes with one-click copy.

## Features
- 100 hand-crafted themes across 9 categories (Dark, Light, Minimal, Vibrant, Retro, ICT/SMC, Legends, Social, ChartThemes)
- Realistic chart previews with price & date scales
- One-click auto-copy for every color code (candles, background, grid, FVG/CRT tools, Long/Short position tool)
- Favorites (saved in browser), Random Theme picker, search & category filters
- Full-page theme details with interactive drag-to-pan hero chart
- Fully self-contained single HTML file — no build step, no dependencies

## Usage
Open index.html in any browser, or host it with GitHub Pages:
Settings → Pages → Source: main branch → your site goes live at https://imrandev3.github.io/tradingview-themes/
