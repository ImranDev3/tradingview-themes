# 📈 TradingView Themes — ChartSkins

**100 hand-crafted professional TradingView chart color themes** with one-click color copy. Dark, Light, Minimal, Vibrant, Retro, ICT/SMC, Legendary Traders, Social Viral & ChartThemes collections — every theme ships with the full palette: candles (body + border + wick), background, grid, FVG/CRT tools, and Long/Short position tool colors.

## ✨ Features

- 💯 **100 themes** across **9 categories** — Dark, Light, Minimal, Vibrant, Retro/Terminal, ICT/SMC, Legendary Traders, Social/Viral, ChartThemes Collection
- 📊 **Realistic chart previews** — price scale, date scale, current-price highlight, crisp candles in every theme's true colors

## 🛠️ How to Apply a Theme in TradingView

1. Click a theme → hit **Copy All Codes** (21+ colors)
2. In TradingView: right-click chart → **Settings** → **Symbol** tab → paste candle Body/Border/Wick colors
3. **Appearance** tab → Background, Grid, Watermark, Crosshair
4. **Scales** tab → Text color
5. **Template → Save As Default** — done! Every new chart loads your theme
